# Misión 01 — Ficha de personaje

Esta entrega presenta la ficha de Tilín, un personaje viral de internet conocido por
sus bailes y su traje llamativo.
La página se construyó únicamente con HTML semántico; no contiene CSS.

## Archivos

- `index.html`: página principal de la ficha.
- `assets/tilin.jpg`: retrato del personaje. Debe añadirse antes de entregar.
- `IA.md`: declaración detallada del uso de IA y de la revisión realizada.

## Cómo abrirla

Abre `index.html` en un navegador o usa la extensión Live Server de VS Code. Antes
de entregar, valida el HTML en W3C y ejecuta Lighthouse para revisar accesibilidad.
